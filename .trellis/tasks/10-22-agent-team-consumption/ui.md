# UI：代理团队消费页

原则：一屏回答四个问题——团队花了多少、我赚了多少、谁在花 / 谁不来了、某个客户具体用了什么。三层页面共用同一骨架，只换范围。

## 1. 路由与骨架

| 路由 | 内容 | 可见 |
|---|---|---|
| `/affiliate/team` | 团队总览 | 有准入者 |
| `/affiliate/team/agents/:id` | 某二级代理的团队 | 有下级代理者 |
| `/affiliate/team/customers/:id` | 单个客户 | 范围内客户 |

骨架（三页一致）：

```
团队消费 / 小王 / 张三                              [最近 7 天 ▾]  ⟳
─────────────────────────────────────────────────────────────────────
摘要条（一张卡内横排指标）
─────────────────────────────────────────────────────────────────────
每日趋势（2/3 宽）                        │ 模型分布（1/3 宽）
─────────────────────────────────────────────────────────────────────
表格
```

- 面包屑即标题，按归属层级生成，与来路无关：我的客户 →「团队消费 / 张三」；小王的客户 →「团队消费 / 小王 / 张三」。
- 被降级用户：面包屑下一行灰字「你当前不是代理，以下为代理期间归属你的客户，分润照常」。

## 5. 交互规则

1. 时间范围：默认最近 7 天，最长 90 天，快捷项沿用现有日期选择器。切换后摘要、图表、表格同时刷新，页码归 1，排序保留。
2. URL 状态：时间范围、Tab、排序、页码、搜索、模型 / 分组筛选写入 query；下钻只携带时间范围；浏览器返回恢复上一层列表状态。
3. 排序：点表头切换降序 / 升序。客户表可排：消费、请求、收益、最近使用，默认消费降序；下级代理表可排：团队消费、收益、活跃，默认团队消费降序。
4. 点击：客户行 → 客户详情；代理行 → 团队页；已删除客户不可点。
5. 模型分布：只在客户详情可点，点击即设置明细的模型筛选，再点取消；总览与团队页只读。
6. 趋势：按天；只选一天时显示单柱。
7. 搜索：输入停止 300ms 后查询；昵称模糊、邮箱完整匹配。
8. 空态：无客户 →「还没有客户」+「去邀请」链接到 `/affiliate`；范围内无消费 → 图表区显示「该时间段没有消费」，表格照常列出客户。
9. 越权或不存在：统一显示「客户不存在或无权查看」+ 返回团队消费。
10. 加载：首次骨架屏；之后切换保留旧数据，表格上方细进度条，避免闪烁。
11. 格式：金额 ¥ 两位小数，明细扣费四位；Token 用 K / M；最近使用为相对时间，悬停显示精确时间，从未使用显示 `-`。
12. 移动端：摘要指标两列换行；趋势与模型分布上下排列；表格横向滚动，客户列固定在左侧。

## 6. 入口（已改为标签，见第 7 节）

- 代理：邀请返利页代理卡片右上角文字按钮「团队消费 →」。
- 被降级但有老客户的用户（页面上没有代理卡片）：「成为代理」卡片内追加一行「代理期间的客户仍在为你带来收益 · 团队消费 →」。
- 是否显示由 `/user/aff` 新增的 `team_access` 决定。
