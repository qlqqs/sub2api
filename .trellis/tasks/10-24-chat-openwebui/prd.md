# 对话工作台：二开 Open WebUI 原生嵌入

## Goal

在 sub2api-custom（一号机站点 QxAPI）里提供一个类似 ChatGPT 网页版的对话工作台：
用户登录本站后直接在网页里和模型对话，不需要自己装客户端、配 Base URL 或复制 Key，花费照常从本站余额扣。
界面看起来是控制台原生的一部分（参照创作工作台 `/studio` 的嵌入效果）。

基础是二开 Open WebUI，以 v0.12.3（2026-10-16）为起点，改动保持为补丁集并定期变基到上游。
fork 仓库：`qlqqs/open-webui`（公开，已创建），本地 `~/workspace/open-webui`。调研见 `research/`。

## 用户与场景

- 定位：面向小白或低强度使用者，日常问答、带文档对话、生图这类简单任务。
- 规模：约十几个用户（许可证约束见「约束」）。
- 普通用户从控制台侧边栏「对话」进入：多轮对话、切换模型或预设助手、上传图片 / 文档提问、联网搜索、生图、查看历史会话。
- 管理员（sub2api 管理员）额外负责：在 Workspace 里做预设助手与提示词库；配置插件（Tools / Functions）与 MCP / 工具服务器供用户使用。不在 Open WebUI 里另配渠道或 Key。

## 范围

### 一期保留（对普通用户）

- 会话侧栏：新建、历史、搜索、文件夹、置顶、重命名、删除、归档、临时对话。
- 回复：流式输出、Markdown / 代码高亮 / 公式 / mermaid、思考过程、复制、重新生成、编辑、继续生成、分支切换、Artifacts / HTML 预览。
- 输入：附件（图片、文档，原版行为，见 R9.5）、模型 / 预设助手选择、`/` 提示词库、联网搜索开关（模型原生搜索，见 R10）、生图。
- Agent：原版原生函数调用 + 内置工具（读附件、搜历史会话、笔记、待办、时间、向用户追问）+ 管理员配置的工具。
- 对话参数面板（系统提示词、温度等）。
- 笔记、日历。
- 设置：通用、界面、模型与密钥（新增）、数据（导入 / 导出 / 清空）。

### 一期保留（仅管理员）

- Workspace：预设助手（自定义模型：绑定模型 + 系统提示词）、提示词库。
- 管理后台中只开放：函数（Functions）、工具（Tools）、工具服务器（MCP / OpenAPI）。其余管理页屏蔽。

### 二期

- 自动化（定时运行提示词，结果写入会话）：后台运行时拿不到请求注入的 Key，需另行设计。
- 多模型并排对比。

### 做不了（网关没有对应能力）

- 记忆、知识库、文件问答（RAG / 向量检索）：网关没有 embedding 模型。
- 语音输入、朗读、语音通话：网关没有 `/v1/audio`。

### 屏蔽

见 R9。

## Requirements

### R1 嵌入与部署

- R1.1 Open WebUI 代码只在 fork 仓库，不进入 sub2api 仓库；sub2api 只引用其镜像。
- R1.2 部署为独立 compose 项目，只与 sub2api 通过内部网络通信；不映射宿主机端口。
- R1.3 外网入口不变：1Panel 仍只把整个域名反代到 sub2api；Open WebUI 的静态资源、接口、WebSocket 全部由 sub2api 内部转发，路径不得与 sub2api 现有路径（`/api/v1`、`/v1`、`/v1beta`、`/_nova`、`/api/nova`、SPA 路由）冲突。
- R1.4 sub2api 通过配置开关启用；未配置或 Open WebUI 不可达时，入口隐藏、转发返回 503，其余功能不受影响。
- R1.5 控制台页面内以同源 iframe 嵌入；无边框、占满内容区、只有一层滚动，随侧栏收起 / 移动端自适应。
- R1.6 入口名称「对话」，路由 `/chat`，放在「创作工作台」旁边。

### R2 账号与身份

- R2.1 用户无需二次登录、注册；Open WebUI 内看不到登录 / 注册 / 退出 / 改密码入口。
- R2.2 身份以 sub2api 登录态为准：sub2api 转发时校验登录态，注入用户 ID 与角色；Open WebUI 只信任经 sub2api（可信网段）转发来的身份，客户端自带的同名头一律丢弃。
- R2.3 sub2api 管理员对应 Open WebUI 管理员（只能使用一期开放的管理功能），普通用户对应普通用户；新用户首次进入自动开通，不需要审批。角色每次请求按 sub2api 同步。
- R2.4 sub2api 退出登录或切换账号后，Open WebUI 立即失效当前会话，不显示上一个用户的数据。
- R2.5 不存在绕过 sub2api 身份的入口（Open WebUI 自己的登录接口、API Key、OAuth 等全部关闭）。

### R3 数据隔离

- R3.1 会话、消息、上传的文件、笔记、日历、设置都归属用户；非本人访问一律拒绝（与不存在相同）。
- R3.2 同一浏览器切换账号后看不到上一个账号的本地数据（草稿、设置、缓存）。
- R3.3 不对用户设额外限额；用户仍受网关自身限制（并发、RPM、Key 额度与余额）。

### R4 固定网关与出网

- R4.1 界面不出现 Base URL、自填 Key、添加模型连接的入口；连接配置锁定为网关，管理员也不能改。
- R4.2 所有模型请求（对话、联网搜索、生图、标题 / 标签 / 追问建议等后台任务）一律只发往内网网关地址，并使用当前用户所选的 Key 计费。
- R4.3 调网关时携带用户真实 IP（`X-Forwarded-For`），使 Key 的 IP 白名单、风控、使用记录中的 IP 正确。
- R4.4 Open WebUI 服务端除网关外默认不访问任何外网（模型下载、版本检查、遥测、原版联网搜索、网页抓取、头像等全部关闭）。
- R4.5 管理员配置的插件 / MCP 需要访问外部服务时，只能经出站代理访问管理员登记的白名单域名；其余一律拒绝。

### R5 模型与密钥

- R5.1 「模型与密钥」：Key 下拉只列当前用户自己的 sub2api Key；禁用、过期、额度用完的置灰并说明原因。
- R5.2 模型列表来自所选 Key 在网关上实际可用的模型；显示单价，格式与模型广场一致，不显示「倍率」字样。管理员的预设助手只在其底层模型对所选 Key 可用时显示。
- R5.3 没有可用 Key 时提供「一键创建」。
- R5.6 另有一个可选的「生图 Key」（同样只列本人 Key，只列支持生图的分组）：生图走它计费，对话仍走对话 Key；未设置生图 Key 时，若对话 Key 支持生图则用对话 Key，否则不显示生图开关并提示去设置。
- R5.4 只记住 Key ID 与模型选择，不在 Open WebUI 数据库或浏览器持久化 Key 明文；浏览器全程看不到 Key 明文。
- R5.5 首次进入未选择 Key 时引导到该设置。

### R6 余额与费用

- R6.1 余额只显示在控制台顶栏；每轮回复结束后通知父页刷新余额。
- R6.2 余额不足、限流、内容审核、Key 失效等网关错误转为中文提示；余额不足时提供「去充值」入口。
- R6.3 计费完全由 sub2api 网关按所选 Key 完成，不存在第二套余额或积分。

### R7 UI 风格

- R7.1 与创作工作台一致：iframe 内不显示任何品牌（不显示 Open WebUI，也不显示 QxAPI 的名称或图标）；页面标题只是控制台菜单栏里的「对话」。版权声明与 LICENSE 链接以小字保留在设置页底部。
- R7.2 配色取控制台 token（主色、底色、1px 细线），深 / 浅色跟随控制台；设置里不提供主题选择。
- R7.3 中文界面，跟随控制台语言；设置里不提供语言选择。
- R7.4 侧栏底部的头像菜单换成一个「设置」按钮；去掉更新日志、更新提示、横幅、新手引导、启动画面品牌。
- R7.5 对话参数面板保留；不额外做「小白简化」（2026-10-24 用户拒绝：隐藏参数面板、预设助手置顶、默认 Key / 默认助手）。

### R8 Artifacts

- R8.1 模型生成的 HTML / SVG / 图表在独立沙箱中预览，不能读取本站页面、Cookie 或存储，不能访问外网。

### R9 屏蔽清单（接口与界面都屏蔽，不只是关开关）

- R9.1 网关无对应能力：记忆、知识库、文件问答（RAG / 向量检索）、语音输入、朗读、语音通话。
- R9.2 安全 / 出网：
  - 普通用户：创建或导入插件（Tools / Functions / Pipelines）、添加 MCP / 工具服务器、直连工具服务器。
  - 所有人：代码解释器 / 代码执行、终端、原版联网搜索（Open WebUI 自建搜索引擎）、按网址抓取网页、YouTube、从 URL 导入插件、pip 自动安装插件依赖。
  - 跨用户：会话分享、社区分享、频道。
- R9.3 与 sub2api 重复：Open WebUI 自己的注册、登录、找回 / 修改密码、个人 API Key；管理后台中除「函数 / 工具 / 工具服务器」以外的全部页面（用户、设置、连接、模型、评测、统计、Playground 等）。
- R9.4 模型竞技场（Evaluation Arena）与回复下的点赞 / 点踩评分。
- R9.5 附件：按 Open WebUI 原版行为，不另做定制。
  - 图片：原版方式发给视觉模型。
  - 文档（PDF、docx、txt / md / 代码 / csv / html 等）：原版加载器提取文字。因网关无 embedding，使用原版的「全文模式」（`BYPASS_EMBEDDING_AND_RETRIEVAL=true`）；开启原生函数调用时，模型可用原版内置工具 `list_chat_files` / `grep_chat_files` / `view_file` 按需读取。
  - 唯一偏离：slim 镜像对 PDF / docx 直接拒绝（`retrieval/loaders/main.py:720-732`），fork 镜像补装原版完整镜像本来就有的 `pypdf`、`docx2txt`，让原版加载器可用；不改加载逻辑。
  - 扫描版 PDF（无文字层）与原版一样读不出内容。
  - 文件大小上限由 sub2api 转发层限制。
- R9.6 每一项被屏蔽的功能都要同时满足：界面上没有入口（按钮、菜单、设置分区、快捷键、斜杠命令）；后端接口返回 404 / 403；环境变量层面关闭。
- R9.7 自动化一期屏蔽（二期再开）。

### R10 联网搜索与生图

- R10.1 输入框保留「联网搜索」开关；打开时只在请求里加入模型原生的 `web_search` 工具，由网关转换为 OpenAI / Anthropic 原生搜索或网关模拟搜索；Open WebUI 服务端不发起任何搜索或网页请求。
- R10.2 生图：原版生图功能接网关 `/v1/images/*`，按生图 Key（R5.6）计费；生成结果只接受 base64 或网关地址，不下载外部链接。
- R10.3 引用：联网搜索的来源在回复下方显示（「N 个来源」）。OpenAI 分组走 Responses 接口，已可显示；Claude 分组需要网关在 Chat Completions 转换中输出标准 `url_citation` 注释（本任务内改网关，见 design §7.1）。
- R10.4 搜索费：网关目前不对原生搜索按次计费（只收 token 费），保持现状，由平台承担上游搜索费（2026-10-24 用户决定）。
- R10.5 后台任务：只保留会话标题生成；标签生成、追问建议关闭（每次都是用户 Key 上的一次计费调用）。

## 约束

- **许可证（Open WebUI License，BSD-3 + 第 4 条品牌条款）**：只有在「任意连续 30 天内直接使用该应用的自然人不超过 50 人」时才能修改或去除 Open WebUI 品牌。
  - 超过 50 人时必须恢复 Open WebUI 品牌（或取得书面许可 / 企业授权）；去除品牌做成部署配置，可随时切回。
  - 条款同样约束「分发」：fork 仓库与镜像公开，源码与镜像默认保留 Open WebUI 品牌，只在我们的部署里隐藏。
  - 保留版权声明、LICENSE、LICENSE_HISTORY、LICENSE_NOTICE。
  - 不使用需要企业授权的功能（Terminals 等）。
- 补丁集 + 定期变基：fork 改动尽量集中在新增文件，路径前缀等机械改动由 codemod 脚本生成，变基时重跑脚本；每次变基后跑完整 e2e。
- 管理员安装的插件运行在 Open WebUI 服务器进程内，能看到当次请求里的用户 Key：只安装可信插件。
- sub2api 侧改动集中在 fork 自有文件（参照 `studio_proxy.go`），上游文件只做挂接。
- 先在本机测试环境（`~/workspace/sub2api-local`）验证全部通过，再经用户同意提交、推送、部署一号机。
- 本机环境隔离规则不变：只监听 127.0.0.1、名称不与其他部署冲突、禁止全局 Docker 清理。

## Acceptance Criteria

- [x] 登录用户进入对话页、选好 Key 后即可对话；扣费与 usage 记录与直接调 API 一致（同 Key、同模型、同 token、同金额）；后台任务（生成标题等）、联网搜索、生图也计在该用户所选 Key 上。
- [x] 用户 A 拿 B 的会话 ID / 文件 ID / 笔记 / 日历访问一律被拒绝；WebSocket 不推送他人数据。
- [x] 同一浏览器切换账号后看不到上一个账号的会话、设置、草稿。
- [x] 伪造身份头（直连 Open WebUI、或经 sub2api 带 `X-Sub2API-*`）不能冒充他人或提权为管理员；Open WebUI 自带登录 / 注册 / API Key 接口不可用。
- [x] 构造任意上游地址（客户端参数、管理员连接设置）时，服务端不向网关以外的地址发起请求；运行期间确认除网关与出站代理白名单外无其他外网连接。
- [x] 网关 usage 中的客户端 IP 为用户真实 IP；Key 的 IP 白名单对对话请求生效。
- [x] 联网搜索开关打开时，请求带原生 `web_search` 工具且 Open WebUI 服务端无出网；生图经网关计费。
- [x] 普通用户看不到 Workspace、管理后台、添加工具服务器的入口，调用对应接口被拒绝；管理员能做预设助手、提示词库，能配置插件与 MCP，看不到其他管理页。
- [x] R9 屏蔽清单中的每一项：界面无入口、接口 404 / 403。
- [x] 余额不足时给出中文提示与充值入口。
- [ ] 视觉与控制台无缝：无 iframe 边框、无双层滚动、无任何品牌与头像菜单，深浅色跟随，截图经用户确认。
- [x] 未配置时入口隐藏、相关路径返回 503，原有 e2e（p0–p8）全部通过。

## Decision Log

- 2026-10-24 选型：二开 Open WebUI（候选 LibreChat、HF chat-ui、Nuxt UI 模板等）。理由：界面最接近 ChatGPT、功能最全、原生信任头登录、单容器；用户规模约十几人，满足品牌条款例外。
- 2026-10-24 安全维护：「补丁集 + 定期变基」，每 1–2 个月或出现影响已开放功能的高危通告时变基到上游最新版，跑完整 e2e 后发布（最初讨论的「锁定版本、不跟上游」放弃）。依据：上游 2026 年已发布 159 个安全通告（`research/security-deploy.md`）。
- 2026-10-24 呈现方式与创作工作台一致：控制台内同源 iframe、看起来像原生；iframe 内不显示任何品牌。
- 2026-10-24 fork 仓库与镜像公开，默认保留 Open WebUI 品牌，只在我们的部署里用环境变量隐藏。用户已知悉此做法在「分发」解释上存在灰色地带。
- 2026-10-24 记忆因网关没有 embedding 模型取消；语音因网关没有 `/v1/audio` 取消。
- 2026-10-24 屏蔽清单 R9：接口 + 界面都屏蔽。
- 2026-10-24 笔记、日历保留；Playground、模型竞技场（含点赞 / 点踩）屏蔽；自动化放二期。
- 2026-10-24 附件按 Open WebUI 原版行为处理（不做 PDF 原样发送、Word 转 Markdown 等定制）；只为 slim 补装 `pypdf`、`docx2txt`。
- 2026-10-24 插件（Tools / Functions）与 MCP / 工具服务器只允许管理员配置；需要出网时经白名单出站代理。
- 2026-10-24 联网搜索用模型原生搜索（网关已支持 `web_search` 转换），不用 Open WebUI 自建搜索。
- 2026-10-24 生图纳入一期。
- 2026-10-24 Workspace 只给管理员，用于预设助手与提示词库。
- 2026-10-24 不做额外的「小白简化」。
- 2026-10-24 PoC 完成（`research/poc.md`），无阻塞项。
- 2026-10-24 联网搜索：网关只补引用（Claude 分组），搜索按次计费不做，搜索费平台承担。
- 2026-10-24 生图：「模型与密钥」里单独选一个生图 Key。
- 2026-10-24 后台任务：只保留标题，关闭标签与追问建议。
- 2026-10-24 每用户计费：Key ID 存 Open WebUI 用户设置，sub2api 反代按 ID 校验归属后注入明文 Key；浏览器看不到明文（design §3）。不改网关鉴权。

- 2026-10-25 经用户明确同意发布修复，一号机对话工作台上线 `126b01b`；真机复测和凭据清理通过。最终外观截图已展示，用户视觉确认单独待反馈，尚不归档。
