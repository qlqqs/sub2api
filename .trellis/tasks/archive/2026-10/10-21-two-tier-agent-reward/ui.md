# UI 与操作逻辑

## A. 后台 · 系统设置 → 邀请返利（只放规则）

```
┌ 代理利润 ───────────────────────────────────────────────┐
│ 返利基数  (●消费  ○充值)        结算周期 [60] 分钟（仅消费）│
│ 利润池（一级比例） [30]%        二级代理比例 [20]%          │
│ □ 启用专属比例（覆盖代理本档比例，上级拿差额）              │
│ 有效期 [0] 天  冻结期 [0] 小时  单人上限 [$0]（0=不限）     │
│ ┌ 示例：归属二级代理的客户消费 $100 ───────────────────┐ │
│ │ 二级代理 $20 · 一级代理 $10 · 平台 $0                  │ │
│ │ 二级代理本人消费 $100 → 一级代理 $30                    │ │
│ │ 无一级上级的二级代理 → 自己 $30                          │ │
│ └──────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────┘
┌ 代理升级 ───────────────────────────────────────────────┐
│ 升级方式 (●手动  ○自动)   ← 默认手动                       │
│ （选自动后才显示）人数口径 (●全部直属 ○仅充值过)            │
│ （选自动后才显示）升二级 [5] 人  升一级 [20] 人（0=该级不自动升）│
│ （选自动后才显示）[按当前条件重新评估全部用户]                │
│ ☑ 允许一级代理任命直属用户为二级   每人最多 [0] 个（0=不限）  │
└──────────────────────────────────────────────────────────┘
┌ 普通用户邀请奖励（额外支出，不占利润池）─────────────────┐
│ 模式 (●关闭 ○按比例 ○首充固定金额)                         │
│  按比例：好友每笔 [5]%  有效期 [0] 天  单人上限 [$0]        │
│  首充固定：好友首充满 [$10] 奖励邀请人 [$2]                 │

┌ 被邀请人首充奖励 ───────────────────────────────────────┐
```

校验：比例 0–100；二级比例 > 利润池时字段标红并禁止保存；金额 ≥ 0；切换模式只显示对应字段；示例随输入实时刷新。

## B. 后台 · 邀请返利 → 新增「代理管理」页
现有导航：邀请记录 / 返利记录 / 转出记录 → 新增 **代理管理**（放第一个）。
设置页原「专属用户」列表迁移到这里，设置页只保留规则。
等级列下方小字显示来源：管理员设置 / 自动升级 / 由 a@x.com 任命。

```
[搜索用户] [等级: 全部▾] [上级代理: 不限▾]        [+ 设置代理] [批量设等级]
┌──┬──────────┬────────┬────────┬──────┬──────┬────────┬──────┬────────┐
│☐ │用户      │等级    │归属代理│直属邀请│归属客户│累计分润 │专属比例│操作    │
├──┼──────────┼────────┼────────┼──────┼──────┼────────┼──────┼────────┤
│☐ │a@x.com   │一级     │—       │32    │120   │$812.40 │—     │调整 ⋯  │
│☐ │b@x.com   │二级 🔒  │a@x.com │8     │15    │$96.00  │25%   │调整 ⋯  │
│☐ │c@x.com   │普通     │b@x.com │2     │—     │—       │—     │调整 ⋯  │

```
- 「调整」弹窗：等级（普通 / 二级 / 一级）、专属比例、专属邀请码、解锁自动升级。
  - 降级时提示「降级后将锁定自动升级；TA 已有客户的分润不变，之后新绑定的用户不再归 TA」，二次确认。
  - 升级不锁定。
  - 管理员可覆盖一级代理的任命，来源随之变为「管理员设置」。
- 「⋯」菜单：查看客户（抽屉列出归属该代理的客户与贡献）、查看返利记录（跳到返利记录并按该用户筛选）、清除专属设置。
- 「+ 设置代理」：搜索用户 → 选等级 → 确认（即手动升级）。

## D. 用户端 · 我的邀请

普通用户：
```
┌ 邀请好友 ────────────────────────────────────┐
│ 好友首充满 $10，你得 $2；好友首充额外送 10%      │  ← 按已开启的奖励动态生成
│ 邀请码 [XXXX] [复制]   链接 [...] [复制]        │
└──────────────────────────────────────────────┘
┌ 成为代理 ─────────────┐ ┌ 返利余额 ─┐ ┌ 累计收益 ┐
│ 再邀请 3 人升为二级代理 │ │ $2.00     │ │ $6.00    │
│（不展示代理比例）       │ │ [转入余额] │ │ 冻结 $0  │
└───────────────────────┘ └───────────┘ └──────────┘
邀请列表：好友（脱敏）· 注册时间 · 为你带来的收益
```
代理：
```
┌ 二级代理 ───────────────────────────────────────┐
│ 客户消费的 20%（专属比例时显示专属）               │
│ 归属客户 15 人 · 再邀请 12 人升为一级代理（仅自动模式）│
└────────────────────────────────────────────────┘
┌ 返利余额 ┐ ┌ 累计收益 ──────────────────────┐
│ $40.00   │ │ $96.00 = 代理分润 $90 + 邀请奖励 $6│
└──────────┘ └────────────────────────────────┘
邀请列表：好友（脱敏）· 注册时间 · 归属（我的客户 / 其他代理的客户）· 为你带来的收益
```
代理的「邀请好友」卡片只展示好友能得的首充奖励（「好友首充额外送 10%」），不展示邀请人首充奖励——代理只拿分润。
一级代理的邀请列表多一列「代理身份」和操作（开关开启时）：
```
已任命二级代理 2 / 不限
┌──────────┬──────────┬──────────┬──────┬──────────────┐
│好友      │注册时间  │归属      │收益  │代理身份        │
│b***@x.com│2026-10-01│我的客户  │$12.0 │二级 [取消]     │
│c***@x.com│2026-10-05│我的客户  │$3.0  │普通 [设为二级] │
│d***@x.com│2026-09-20│其他代理的│$0    │—（不可任命）   │
└──────────┴──────────┴──────────┴──────┴──────────────┘
```
- 设为二级：确认框「设为二级代理后，TA 之后邀请的用户归 TA，TA 得 20%，你得 10%；已有用户不变」。
- 取消：确认框「取消后 TA 之后邀请的用户归你；TA 已有客户的分润不变」。
- 达到上限时「设为二级」置灰并提示。
手动模式（默认）或用户被锁定时，不显示升级进度，「成为代理」卡片改为「代理资格由管理员开通」。

## E. 用户端 · 充值页与注册页
- 充值页：有邀请人、尚未发过首充奖励、且开启被邀请人奖励时，金额区上方显示「首次充值满 $10 额外赠送 10%（最多 $20），到账后发放」；输入金额 ≥ 门槛时报价明细多一行「首充奖励 +$X（到账后发放）」，低于门槛时提示「再充 $Y 可获得首充奖励」。未达门槛的充值不消耗资格，之后第一笔达到门槛的充值仍可获得。
- 注册页：通过邀请链接打开且开启了被邀请人首充奖励时，显示「通过邀请注册，首充可额外获得 …」（不区分邀请人是普通用户还是代理）。

## F. 操作逻辑

### F1. 管理员初始化
开启邀请返利 → 配置代理利润 → 配置升级方式 → 配置两类邀请奖励 → 到「代理管理」手动设置首批一级/二级代理。

### F2. 用户成为代理
默认手动：只有管理员在「代理管理」页设置的用户才是代理。
- 自动（需在设置页切换为自动）：有人绑定为其直属时评估；人数口径为「仅充值过」时，其直属首次充值完成后也评估。只升不降，锁定用户跳过。
- 手动：代理管理页调整等级。降级锁定，升级不锁定。
- 升级、降级都只影响之后新绑定的关系；已有客户的分法按绑定时快照不变。

### F3. 邀请绑定
注册带邀请码 / 管理员绑定 → 写邀请人 + 归属代理 → 触发邀请人自动升级评估。

### F4. 收益产生与到账
- 消费模式：每个结算周期汇总余额消费（按真实充值封顶）→ 按规则计算代理分润与普通邀请比例奖励 → 进入返利余额（有冻结期则先冻结）→ 用户手动「转入余额」。
- 充值模式：支付成功即按同一规则计算。
- 首充：支付成功后判断首充与门槛 → 被邀请人赠送直接进余额；邀请人固定奖励进返利余额。每人只发一次。

### F4.1 一级代理任命二级
一级代理在「我的邀请」列表中对归属自己的直属用户点「设为二级」→ 确认 → 立即生效；可随时「取消」自己任命的二级。

### F5. 代理降级 / 删除
- 降级：已有客户的分润按快照继续发给 TA；之后新绑定的人沿链向上找当前仍是代理的人归属；TA 本人消费按当前等级分法。
- 删除：TA 自己那份不再发，同一关系里其他人的份额不变；客户的归属记录保留并显示「已删除」。
