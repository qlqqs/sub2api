# 余额显示人民币与分组「¥x = $1」比例

## 背景
本站充值 ¥1 到账 1 个余额单位（充值倍率固定为 1），分组倍率 r 通常小于 1（如 0.5）。
模型单价沿用官方美元价。当前全站把余额单位显示成 $，又用「0.5x」表示倍率，
小白用户既看不懂余额与官方价的关系，也算不出实际有多便宜。

## 核心口径
- **¥ = 用户的钱**：余额、充值到账、每次扣费、各类限额、兑换码、返利等所有「站内余额单位」一律显示 ¥。数字不变，不做汇率换算。
- **$ = 官方用量**：模型单价（官方价/渠道单价）及「按官方价折合」的用量保持 $。
- **比例 = 「¥x = $1」**：x = 生效倍率（充值倍率固定为 1，不参与计算）。生效倍率优先用该用户的专属倍率，没有则用分组倍率。
  例：分组倍率 0.5 → 「¥0.5 = $1」；用户专属倍率 0.3 → 该用户看到「¥0.3 = $1」。
- 不引入汇率、不展示「省 X%」。

## 已确认规则
1. 充值倍率固定为 1，不会变动；比例直接等于生效倍率（用户确认）。
2. 比例按用户自己的生效倍率计算（专属倍率 > 分组倍率）。
3. 高峰时段倍率、生图/视频独立倍率：在各自显示倍率的位置同样换算为「¥x = $1」（x 用该场景的生效倍率）。
4. 真实币种不改：支付订单的实付金额（按订单币种）、上游供应商账号余额（如 DeepSeek CNY/USD）保持各自币种。
5. 中英文界面都用 ¥ 表示余额单位（它是站内计价单位，与语言无关）。
6. 只改展示：不动数据库、计费、充值到账逻辑与 API 字段名（如 `*_usd` 字段保持不变）。

## 展示位置
| 位置 | 改成 |
|---|---|
| 余额、扣费、限额、兑换码、返利、提现、后台余额调整/流水、排行等 | $ → ¥ |
| 选分组（创建/编辑 Key、Key 列表分组标签、可用渠道） | 「0.5x」→「¥0.5 = $1」，原倍率放悬停提示 |
| 模型广场 | 官方价 $/百万；本站价 ¥/百万（= 单价 × 生效倍率）；倍率列 →「¥x = $1」 |
| 充值页 | 「充 ¥100 → 余额 ¥100」；列出用户可用分组的「¥x = $1」 |
| 仪表盘 | 「实际花费 ¥x，官方用量 $y」（x = actual_cost，y = 标准费用 total_cost；全站统一：actual_cost 用 ¥，total_cost/标准费用用 $） |
| 使用记录 | 扣费显示 ¥；悬停显示「官方价 $y」 |
| 邮件 | 余额不足提醒、充值成功通知中的 $ → ¥ |

## 验收
- 用户端与管理端所有余额单位显示为 ¥，官方单价显示为 $，真实币种不变。
- 有专属倍率的用户在分组选择、模型广场、充值页看到的比例按专属倍率计算。
- 余额符号与比例格式只在一处定义（共享工具函数），各页面统一调用。
- 前端类型检查、lint、i18n 检查、vitest、构建通过；后端相关测试通过。
