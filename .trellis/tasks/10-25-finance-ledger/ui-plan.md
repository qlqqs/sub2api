# 集中成本设置与历史重算：UI 规划

状态：用户最新确认 A 表格 + 现有 BaseDialog 居中弹窗 + D 三步重算（取消右侧抽屉）。UI 规划已定，尚未批准正式开发，原型未接入真实接口。

## 设计读取与目标

管理后台财务配置页，面向站长日常核账；沿用 QxAPI 蓝白 / 深色 token、中文系统栈、紧凑数据表。视觉冒险度 3（稳健）、动效 2（仅反馈）、信息密度 7（同屏核对）；预览拨盘可调整，不影响真实系统。

3 秒内能判断：每个账号怎么算成本、规则从哪里来、当前操作是否改历史。
核心操作：定位账号→编辑其真实配置→保存；单独筛选历史→预览差额→确认重算→检查同步结果。

## 当前证据与问题

- `AdminFinanceView.vue` 的日期/导出工具条和财务警告显示在所有 tab 上；设置是当前配置，应不显示会误导配置生效日期的报表日期控件。历史重算自己选择日期，北京时间。
- `FinanceSettingsTab.vue` 只有固定账号多选，不能快速比较不同账号定价。
- `frontend/src/themes/qx/app/tokens.css` 定义品牌蓝 #1d4eff、白色表面、蓝灰边界及完整深色主题；不替换全站品牌或排版。
- 当前截图（本机测试数据）：`/tmp/finance-ui-plan/current_admin_finance_tab_settings.png`。

## 已确认方向 A：表格 + 现有居中弹窗，重算采用 D 三步

保留财务明细一级 tabs。设置内部使用账号成本 / 支付手续费 / 固定与其他支出 / 历史重算四个二级入口；重算记录是历史重算的内部分页，不再增加一级导航。

### 账号成本

- 表头：账号、成本依据、当前规则摘要、规则来源/作用范围、编辑。搜索名称/ID、按成本类型过滤、分页。
- 显示“固定成本（财务口径）”“按张 ¥0.03 × 倍率 1”“模型倍率（3 条）/默认倍率 0.22”等，不把复杂优先级简化成互斥配置选项。
- 账号列表不会把“固定成本”错误显示为真实 usage 快照为零。
- 编辑弹窗显示账号上下文，分开“默认倍率”“模型倍率”“渠道统计定价”“财务固定成本”；只提交改动字段；来自已有编辑器与后端同一字段。
- 渠道规则列出来源、顺序、匹配账号/分组。共享规则保存前列出受影响对象；高级价格不降级成单一每张价格。
- 默认倍率可能影响调度/限额时提示；单个模型成本倍率强调仅成本快照，不改变用户售价。
- 保存成功显示短提示 + “预览历史重算”次级操作；不自动启动重算、不复写历史。

### 支付手续费

- 按支付实例列出名称、类型、当前通道费率；直接编辑百分比。
- 明确区分平台抽成与向用户加收手续费；不显示支付密钥等不相关字段。
- 注明新订单保存费率快照；旧订单 NULL 回退当前实例费率，显式 0 不回退。
- 保存后给“预览该实例历史手续费修正”，但重算必须另行确认。

### 固定与其他支出

- 复用现有支出列表和弹窗，不复制记录；财务一级“其他支出”仍可访问同一数据。
- 类别、金额、发生日期、关联账号、一次性/按天。上游订阅默认按天 30 天，可切一次性。
- 显示该账号已录入的支出与摊销方式；没有支出时提示录入，而非把固定账号标记解释成自动生成费用。

### 历史重算（独立三步）

1. 范围：上游请求成本 / 支付通道手续费二选一；日期范围、账号与模型或支付实例、使用的当前规则。
2. 预览：扫描数、可修改数、跳过数；旧/新金额及差额；账号/模型汇总可展开逐条，跳过原因可查看。展示锁定规则、数据截止时间，不把演示差额当线上数据。
3. 确认执行：明确写回的成本字段、同步的财务/账号统计/看板，强调不改扣费/余额/分润；确认复选框和语义清晰的执行按钮。

执行状态必须区分：待开始、重算中、同步汇总中、完成、部分失败、失败。只有明细与汇总均更新后才显示“全部完成”。关闭页不取消任务，返回可查看进度；大任务不使用一直遮挡页面的弹窗。

### 记录与撤销

- 批次、操作者、类型、范围、规则快照、旧新值/差额、各同步阶段状态。
- 撤销先预览，不是直接删除记录。后续被其他批次修改的行显示冲突，不能无条件覆盖；允许拒绝并引导处理。

## 四方向独立 brief

| 方向 | 结构与风格 | 排版与密度 | 硬约束 / 取舍 |
|---|---|---|---|
| A 推荐 | 当前蓝白主题；表格横向比较，右侧抽屉编辑 | 系统无衬线标题、等宽金额，中高密度 | 不用卡片替代每个账号行；适合批量核对与多账号 |
| B | 分区设置页；暖灰白纸面、纵向分类表单 | 本机衬线小标题、系统正文，低密度 | 不用账号大表格；各区域独立保存，上手简单但纵向较长 |
| C | 复用深色 token；左账号索引、右侧详情 | 编号与金额等宽，紧凑控台 | 常驻账号上下文、不用抽屉；逐账号深编辑强，横向比较弱 |
| D | 任务入口、步骤向导；白底、蓝色动作与琥珀风险提示 | 较大系统标题、宽行距，任务分阶段 | 一屏一个主动作，不能批量行内编辑；偶尔使用稳妥但步骤多 |

只比较信息架构与局部呈现；不意味着生产版一定切换为某个固定主题。四方向均保留浅/深色实现要求。单 agent 使用独立 brief / scoped CSS 生成，无外部模型调用。

## 交互与响应式约定

- 桌面表格数字右对齐；单位在列头与输入框旁可见，精度与后端一致。
- 窄屏保留账号/成本/编辑核心列，其他摘要折叠，筛选换行；弹窗沿用现有窄屏布局和内部滚动；重算预览表有独立滚动区域，不让全页溢出。
- 空状态、无权限、加载/请求失败、保存失败、配置冲突、预览失效、数据不足、部分失败都有下一步动作。
- 未保存更改离开提醒；Esc/取消恢复焦点；操作可键盘完成；不靠颜色表示增减和状态。
- 当前样机只使用内存示例数据：保存、重算、撤销均不访问业务接口。选择方向才会写本地 selection.json，不代表批准正式实施。

## UI 验收

1. 一个入口修改已有真实字段，原入口读回一致；无重复配置来源。
2. 保存配置与修改历史两个清晰动作，无隐式重算。
3. 重算前看清范围、旧新成本、差额与数据不足；执行后能核实各统计同步结果。
4. 按账号比较成本不必来回打开账号/渠道/支付页面。
5. 1440px / 390px 可读且无页面级横向溢出；同一页面每方向只有一个确认选择按钮。

## 用户确认后的页面结构

```text
财务明细
└─ 设置（当前配置，不显示报表日期 / CSV 导出）
   ├─ 账号成本：可搜索/筛选的表格 → 现有居中编辑弹窗
   ├─ 支付手续费：支付实例表格 → 现有费率编辑弹窗
   ├─ 固定与其他支出：原支出记录 → 复用新增/编辑表单
   └─ 历史重算
      ├─ 1 选择范围（请求成本 / 支付手续费）
      ├─ 2 预览差额（原值、新值、跳过原因）
      ├─ 3 确认执行与同步（明细 → 聚合 → 财务）
      └─ 重算记录 → 明细 / 撤销预览 / 冲突提示
```

- 选择依据：账户数量与成本类型适合横向核对；危险的历史修正保持独立三步，不藏在保存按钮里。
- 保存配置后，不自动跳转、不自动重算；提供“预览历史重算”次级操作。
- 共享规则编辑前显示全部影响对象；账号默认倍率的调度/限额影响单独提示。
- 桌面与手机均复用 BaseDialog 默认布局；列表沿用 DataTable 的窄屏卡片行为，不修改共享组件。
- 本次选择记录在预览目录 `selection.json`，来源是用户对话，不是自动化测试。


## 用户追加修订：复用现有组件、取消抽屉

- 用户要求尽量复用已有组件与样式，并明确“右侧不要抽屉，改成已有的弹窗”。此决策覆盖上文抽屉布局，四方向比较保留为历史材料。
- 账号成本点击编辑 → 原生 `BaseDialog` 居中弹窗（normal），不增加 drawer 变体，不覆盖其定位、宽度、圆角、阴影或遮罩。
- 最新交互 Demo：预览目录 `reuse.html` / `ReuseDemo.vue`。直接导入 `DataTable`、`BaseDialog`、`SearchInput`、`Select`、`DateRangePicker`、`Icon`、`AccountModelCostEditor`、`FinanceExpenseDialog`。
- 直接加载现有 `style.css` 与 Qx `tokens.css` / `app.css`，不维护第二套配色、按钮、表格、表单样式。
- Demo 的 Axios 使用白名单 mock adapter，开发服务拒绝业务 API 路径，无代理到线上或本机应用。
- 最新布局：表格比较 → 现有居中弹窗编辑；历史重算仍为选择范围 → 预览差额 → 确认执行与同步。
- 本轮仍为 UI Demo，不构成业务实现、提交、推送或部署。
