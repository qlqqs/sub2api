# UI：管理端团队消费页

原则：管理员一页回答三个问题——代理渠道带来了多少消费、付出了多少分润、谁贡献最多；点进任一代理，看到的就是该代理自己看到的页面。骨架、组件、交互全部沿用代理端（`10-22-agent-team-consumption/ui.md`），只在下面列出的地方不同。

## 1. 路由

| 路由 | 内容 |
|---|---|
| `/admin/affiliates/team` | 全部代理汇总（新） |
| `/admin/affiliates/team/:agentId` | 某代理视角的团队总览，等同代理端 `/affiliate/team` |
| `/admin/affiliates/team/:agentId/agents/:id` | 该代理下某二级代理的团队，等同代理端 `/affiliate/team/agents/:id` |
| `/admin/affiliates/team/:agentId/customers/:id` | 该代理团队中的单个客户，等同代理端 `/affiliate/team/customers/:id` |

- 顶部栏标题「团队消费」，说明「按代理查看团队的余额消费与分润」，四个页面一致。
- 侧边栏「邀请返利」分组：代理管理、**团队消费**、邀请记录、返利记录、提取记录。

- 根页工具栏左侧不放面包屑（与顶部栏标题重复），只在右侧放日期与刷新。
- 汇总条：三项与代理端摘要条同一排版，主数字下一行小字给占比。
  - 消费：有归属代理的客户的余额消费，每个客户只算一次；小字「占全站余额消费 x%」。
  - 分润 ⓘ：时间段内入账的全部代理分润（不限来源）；小字「占团队消费 x%」；ⓘ 与代理端相同（按入账时间统计、每 N 分钟结算）。
  - 活跃客户：有归属代理的客户中，时间段内有消费的人数 / 总人数。
- 趋势与模型分布：范围同汇总条，只读。
- 等级标签兼作筛选，数字为人数；「已降级」只在有人时出现。
- 表格：
  - 代理：昵称 + 完整邮箱，同一行；已删除显示灰色「已删除 #ID」，仍可点进。
  - 等级：一级 / 二级（后接「· 上级昵称」，无昵称时显示上级邮箱，无上级显示「· 无上级」）/ 已降级。
  - 活跃 / 客户、团队消费：与该代理自己页面摘要条上的「活跃客户」「消费」相同，一级包含其二级团队。
  - 团队消费的底条：占汇总条「消费」的比例（悬停显示百分比）。
  - 分润：与该代理自己页面摘要条上的「收益」相同，即时间段内入账、来源仍在其团队中的代理分润。
- 排序：团队消费（默认降序）、分润、活跃。
- 点击行 → 该代理视角。

## 3. 代理视角 `/admin/affiliates/team/:agentId` 及以下

与代理端三层页面相同（摘要条、趋势、模型分布、表格、请求明细、排序、筛选、分页），差异：

```
团队消费 / 张三                                         [最近 7 天 ▾]  ⟳
zhang@qq.com · #1024 · 一级代理 · 累计分润 ¥8,800.00
[摘要条：消费（直属 · 下级） · 分润 ⓘ · 活跃客户]
[每日趋势]                                   [模型分布]
[直属客户 1,234]  [下级代理 5]                          🔍 邮箱、昵称或 ID
[客户表：客户 | 消费 | 请求 | 分润 | 最近使用]        （邮箱完整显示）
```

- 面包屑首项「团队消费」回到汇总页（带回原来的筛选、排序、页码与日期）；之后按归属层级生成：「团队消费 / 张三 / 小王 / 李四」。
- 元信息行（根页新增）：完整邮箱 · #ID · 等级 · 累计分润（全部历史，与代理管理列表一致）。
  - 二级代理：「二级代理 · 上级 张三」，上级可点，进入张三的视角。
  - 已降级：「已降级 · 代理期间的客户仍产生分润」，代替代理端的降级提示。
- 二级团队页元信息：「wang@163.com · #2048 · 二级代理」或「历史」徽标。
- 客户详情元信息：「li@163.com · #3001 · 小王的客户 · 2026-10-01 绑定 · 累计分润 ¥88.00 · 使用记录 →」；「使用记录」跳到管理端使用记录（本页跳转，浏览器返回可回来），带上该用户和当前日期范围。
- 没有团队（普通用户、ID 不存在）或越权组合（客户不在该代理团队中）：显示「代理或客户不存在」+「返回团队消费」。

## 4. 文案对照（管理端为第三人称）

| 代理端 | 管理端 |
|---|---|
| 我的客户 | 直属客户 |
| 收益（摘要、列、图例） | 分润 |
| 累计收益 {amount} | 累计分润 {amount} |
| 降级提示「你当前不是代理，以下为代理期间归属你的客户，分润照常」 | 元信息行「已降级 · 代理期间的客户仍产生分润」 |
| 历史徽标悬停「TA 已不是你的二级代理，之前的客户仍为你带来差额收益」 | 「已不是 {name} 的二级代理，之前的客户仍为其带来差额分润」 |
| 空态「还没有客户」+「去邀请」 | 「还没有客户」 |
| 搜索「昵称或完整邮箱」 | 「邮箱、昵称或 ID」 |
| 「客户不存在或无权查看」 | 「代理或客户不存在」 |

## 5. 交互规则

沿用代理端第 5 节，补充：

1. URL 状态：汇总页的日期、等级标签、搜索、排序、页码写入 query；下钻只带日期；面包屑首项带回汇总页离开时的 query。
2. 换等级标签：页码归 1，排序与搜索保留。
3. 搜索：输入停止 300ms 后查询；邮箱、昵称模糊，纯数字同时按 ID 精确匹配。
4. 代理管理「⋯」菜单「团队消费」：一级 / 二级代理或有归属客户的用户才显示，打开 `/admin/affiliates/team/:id`。

## 6. 移动端

与代理端第 5 节第 12 条相同：汇总条两列换行；趋势与模型上下排列；表格横向滚动，首列固定。
