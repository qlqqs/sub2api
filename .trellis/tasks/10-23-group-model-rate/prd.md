# 分组内单个模型倍率，用户端不再显示分组倍率

## Goal

管理员可以在分组里给个别模型单独设倍率（例如分组默认 ¥0.6 = $1，`claude-opus-*` 单独 ¥1.0 = $1）；扣费、利润控制、模型广场都按模型倍率生效。一个分组不再只有一个倍率，所以用户端页面不再显示分组倍率，价格一律以模型广场为准。技术方案见 `design.md`，执行步骤见 `implement.md`。

## Background

- 2026-10-23 与用户讨论确定。用户原话：「可以做一个单独模型的倍率。另外分组不再显示倍率，一切以模型广场的价格为准」；并同意以下默认规则：模型倍率优先于用户专属倍率；利润控制按模型倍率；这次不做固定 ¥ 价。
- 现状（2026-10-23 核对）：
  - 上游已有「分组逐模型定价」（`groups.model_pricing`），填的是**美元基础价**，扣费时还要再乘分组 / 专属 / 高峰倍率；想让某模型卖指定 ¥ 价需要手算。本任务不改它，两者可叠加。
  - 模型广场左边 ¥ 价 = 基础价 × 生效倍率，右边官方 $ 价；最后一列「价格比例 ¥x = $1」和分组标签按分组倍率显示，对单独定价的模型不准。
  - 用户端还有 API 密钥页、可用渠道页、充值页、订阅套餐卡、我的订阅页显示分组倍率（清单见 `design.md` 第 5 节）。
  - 代理按消费返利、代理等级都按实扣金额 `actual_cost` 计算，自动跟随模型倍率，不需要改。
- 首页改版（任务 `10-23-qx-theme`）已暂停，本任务优先。它的首页价格按分组倍率计算，恢复后需改用本任务提供的模型倍率（见 R7）。

## Requirements

### R1 管理端配置
- 分组编辑弹窗（新建、编辑）在「分组倍率」下方新增「模型单独倍率」：每行一个模型名和一个倍率，可增删。
- 模型名支持末尾 `*` 通配（如 `claude-opus-*`），大小写不敏感；同一分组内模型名不能重复；倍率须大于 0（与分组倍率相同）。
- 同一模型同时命中多条规则时：精确匹配优先，其次取前缀最长的通配规则。
- 后台分组列表的倍率列在有单独倍率时提示「N 个模型单独倍率」，悬停显示明细。
- 复制分组时一并复制模型单独倍率。
- 简易模式（simple mode）下不显示该配置，与分组倍率一致。

### R2 计费规则
- 一个请求的倍率按其**计费模型**（与「分组逐模型定价」匹配同一个模型名）确定：
  1. 命中该分组的模型单独倍率 → 用它，**用户专属倍率不再作用于这个模型**；
  2. 否则用户在该分组有专属倍率 → 用专属倍率；
  3. 否则用分组倍率。
- 高峰倍率、渠道分时倍率照常叠加在上面。
- 生图 / 视频开启「独立倍率」时仍以独立倍率为准，模型单独倍率不作用；未开启时生图 / 视频模型同样适用模型单独倍率。
- 同一请求的附加费（网页搜索、搜索按次、音频、缓存存储费）与该请求用同一个倍率，与现在行为一致。
- 所有现在算倍率的路径都要一致：Anthropic / Gemini / Antigravity 网关、OpenAI 兼容网关（含 WebSocket、Grok 媒体与音频）、批量生图、预扣冻结（in-flight reservation）、Gemini 缓存固定费报价、按响应模型重新计费。
- 按响应模型重新计费时，「不比原来贵」的判断改为比较乘倍率后的实扣金额（两个模型倍率可能不同）。
- 订阅分组的额度消耗本来就是实扣金额，同样按模型倍率。
- 使用记录 `usage_logs.rate_multiplier` 记录该请求实际采用的倍率。
- 改动后 30 秒内生效（与用户专属倍率的缓存时长相同）；保存时本进程立即生效。

### R3 利润控制
- 分组开启利润控制时，准入阈值里的「下游倍率」按该请求计费模型的倍率计算（规则同 R2，再乘高峰倍率）。
- 后台利润预览按模型分别计算。

### R4 模型广场
- 左边 ¥ 价 = 基础价 × **该模型**的生效倍率（R2 规则，按当前登录用户）；右边官方 $ 价不变。
- 「价格比例」列改名「相比官方价」，逐行显示折扣（用户 2026-10-23 确认）：
  - 比例 = 本站价 ÷ 官方价（¥ / $）；输入、输出价折算出的比例一致时才显示，不一致或没有官方价时显示「—」。
  - 折扣 = 1 − 比例 ÷ 汇率（R8），显示为整数百分比，如 `-95%`；比官方贵时显示 `+5%`；四舍五入后为 0%（绝对值不足 0.5%）时显示「≈ 官方价」。
  - 悬停显示原始比例与换算依据，如「¥0.35 = $1，按 $1 = ¥6.67 折算」。
  - 用户专属倍率生效的行显示「划线公开折扣 + 专属折扣」。分时时段行按该时段价格计算。
- 分组标签不显示倍率；去掉「按价格比例筛选」。
- 高峰提示改为「高峰时段 14:00–18:00 价格上浮 50%」这类说法，不出现倍率数字（倍率小于 1 时写「下调」）。
- 支持 `/model-plaza?group=<id>` 打开后滚动到该分组；分组不可见（如专属分组、未登录）时忽略。未登录跳转登录时保留该参数。
- 未登录提示文案里提到「专属倍率」的地方改为「登录后显示你的专属价格」一类说法。

### R5 用户端不再显示分组倍率
- 以下位置去掉分组倍率与高峰倍率显示，改为「查看价格」链接，跳到模型广场对应分组（模型广场关闭或当前用户无权访问时不显示链接）：
  - API 密钥页：列表分组列、新建 / 编辑时的分组选择（切换分组的弹出列表只去掉倍率，不加链接）。
  - 可用渠道页（桌面与手机布局）。
  - 充值页：「各分组价格」卡片改为一个「查看各分组模型价格」入口；订阅确认、已有订阅里的「价格比例」「高峰价格」去掉。
  - 订阅套餐卡、我的订阅页的「价格比例」「高峰价格」去掉。
- 使用记录 CSV 导出的 `Rate Multiplier` 列保留（该请求实际采用的倍率）。使用记录悬停的费用明细见 R9。
- 管理端所有分组倍率显示不变。
- 接口不删字段（如 `rate_multiplier`、`/groups/rates`），只是用户端页面不再展示，减少与上游的差异。

### R6 模型广场开关提示
- 后台设置关闭模型广场时，开关旁提示：「关闭后用户无处查看模型价格」。

### R8 美元汇率（用户 2026-10-23 确认：默认 6.8，定时从接口更新，默认值兜底）
- 后台定时从公开汇率接口获取美元兑人民币汇率：启动约 1 分钟后取一次，之后每 6 小时一次；按顺序尝试多个来源，第一个成功即采用。
- 取到的值须在 5–9 之间，且与上次采用的值相差不超过 10%，否则丢弃并记警告日志；但同一轮有两个不同来源的值彼此相差不超过 1% 时，视为真实变动并采用（避免旧值偏离后永远更新不了）。
- 生效汇率：开启自动更新且曾成功获取 → 用最近一次成功获取的值（即使已过几天，仍比默认值准）；从未成功或关闭自动更新 → 用默认汇率（初始 6.8，后台可改）。
- 后台系统设置新增「美元汇率」：自动更新开关、默认汇率、当前生效值、来源、更新时间、「立即更新」按钮；超过 3 天未更新成功时显示提醒。
- 出站请求沿用拉取价格表的代理配置（`update.proxy_url`）。
- 汇率只用于显示折扣，不参与计费。

### R9 用户端使用记录的费用明细改为 ¥（用户 2026-10-23 确认：只改用户端）
- 用户端使用记录悬停的「费用明细」：输入费用、输出费用、输入单价、输出单价、缓存创建费用、缓存读取费用、生图输入 / 输出费用与单价、生图单价与总价、按次单价，全部改为 ¥。
- 换算比例 k = 本次实扣 ÷ 原始费用（原始费用为 0 时用该记录的倍率），每项 × k，因此明细合计等于实扣金额（高峰倍率等情况也对得上）。
- 「原始费用 $」保留；原「价格比例」改为「折扣」，= 1 − (实扣 ÷ 汇率) ÷ 原始费用，格式同 R4。
- 管理端使用记录保持美元明细与「价格比例」不变。

### R7 首页（已暂停，记录接口约定）
- 模型广场接口为每个模型返回其倍率字段（见 `design.md` 第 4 节）。首页改版恢复后，`themes/qx/pricing.ts` 改为使用该字段；本任务不改 `themes/qx/`。

## 不做

- 固定 ¥ 价（直接填某模型的 ¥ 单价）。需要时用上游「分组逐模型定价」配美元价。
- `/v1/sub2api/billing`（下游 sub2api 同步账号倍率用）仍只返回分组 / 专属倍率，不含模型单独倍率；下游站点对单独设倍率的模型的成本估算会不准，记为已知限制。
- 按用户 × 模型的专属倍率。
- 首页（`themes/qx/`）的改动。

## Acceptance Criteria

- [ ] AC1 后台可为分组增删模型单独倍率，校验规则符合 R1；复制分组后规则一致。
- [ ] AC2 经网关真实请求（本机 upstream-mock）：分组倍率 1.0、`e2e-model-x` 单独倍率 2.0、用户专属倍率 0.5 时，`e2e-model-x` 的请求 `rate_multiplier = 2`、`actual_cost = total_cost × 2`；其他模型 `rate_multiplier = 0.5`。去掉专属倍率后其他模型回到 1.0，`e2e-model-x` 仍为 2.0。
- [ ] AC3 同一用户先请求有单独倍率的模型、再请求没有的模型，后者不被前者的倍率污染（缓存）。
- [ ] AC4 生图独立倍率开启时，生图模型不受模型单独倍率影响；关闭时受影响。
- [ ] AC5 按响应模型重新计费、预扣冻结、批量生图、利润控制阈值均按模型倍率（单元测试覆盖）。
