## 范围与需求

### R1 集中配置

四区：账号成本、支付手续费、固定与其他支出、历史重算。
账号默认倍率、账号模型倍率、渠道成本定价（按张/次、token 及已有高级规则）、固定成本账号、支付实例通道费率、支出记录，均读写现有字段与原入口相同的数据源。提供搜索、分页、来源/作用范围与影响提示。共享规则编辑须列出影响账号/分组，不简化或丢失高级字段，不覆盖支付密钥。默认倍率参与调度/限额的影响须明确。
保存配置只改变当前规则，绝不隐式重算历史；取消编辑不保存。对跨资源保存报告每项结果，禁止部分成功却提示全部成功。

### R2 预览

上游请求成本与支付通道手续费分别选择。日期采用北京时间闭日期区间，内部转换为半开时间区间；请求按账号/上游模型过滤，手续费按支付实例过滤。
展示锁定规则、数据截止时间、扫描/可修改/不变/跳过数量、旧值/新值/差额及跳过原因。金额单位沿用现有成本/财务转换，不将 USD 与 CNY 混加。
历史依据不足、记录已清理、对象已删除且无法取当前规则、无法可靠复算时保留原值并解释。禁止用 0 或默认 1 张掩盖缺失数据。

### R3 执行与同步

独立二次确认，只执行当前已预览的记录与规则；配置、原值或范围失效时拒绝执行并要求重新预览。防重复执行，任务进度持久化，关闭页面不丢任务；支持失败后安全重试。
请求成本写回成本快照并同步账号统计、小时/日看板聚合及缓存；手续费只修正订单通道费率快照，财务收入确认和利润随现有算法重算，不改变支付金额。
明细成功但聚合/缓存未完成时显示待同步/失败，不能声称完成。任务执行期间明确展示统计可能暂未同步。

### R4 审计（不提供撤销）

保存批次、操作者、规则快照、旧新值（含 NULL）、范围、各阶段状态及失败原因；分页查看。界面和接口均不提供撤销，不实现反向预览或撤销冲突处理。
执行前明确提示「执行后不支持撤销」。失败重试只续做未完成的执行/同步，不恢复已提交旧值；需要再次调整时修改规则后重新预览、确认新的重算批次。

### R5 安全边界

不改用户余额、实际扣费、售价、支付/退款金额、分润流水及已结算分润，不重新触发计费或支付回调。
固定成本只影响财务归类，不把 usage 成本永久置零，不把订阅支出摊入每条请求。
历史重算不回补账号运行时配额/调度计数，避免改变当前流量可用性；修改当前账号默认倍率仍沿用既有行为，需提示。
仅管理员可读写；后端鉴权、审计、限量、冲突与幂等不能只靠前端实现。

## 验收标准

- A1/R1：财务入口保存后原账号/渠道/支付入口读取一致；高级规则、顺序、作用范围及支付凭据不丢失；取消和失败保留正确状态。
- A2/R2：倍率精确/通配匹配、按张与 token 成本、0 倍率、NULL 回退、显式 0 费率、边界日期、缺失依据均有测试；预览不修改业务记录。
- A3/R3：执行结果与预览匹配；重复确认不重复写；配置/原值变化拒绝旧预览；进程重启、同步失败可恢复。
- A4/R3：SQL 核对明细与各成本统计一致；并发网关新增记录、定时聚合及历史保留期边界不导致丢数、重复计费或删除旧汇总。
- A5/R4：审计保留完整旧新值（含 NULL）、操作者和状态；无撤销入口/API，确认弹窗明确不可撤销；失败重试不重复写或恢复已提交旧值。
- A6/R5：前后对比余额、扣费、退款、分润、账号运行时配额不变；非管理员拒绝；无配置凭据进入快照或日志。
- A7/UI：复用现有组件，浅/深色与 390px/1440px 验证；加载、空态、错误、冲突、危险确认和键盘退出可用；中英文 key 对齐。
- A8/发布：本机单元/集成/构建及隔离环境 e2e 通过，提供结果；提交、推送、一号机部署另需用户同意。

## 不在范围内

撤销及撤销冲突处理、自动重算历史、用户价格/代理政策编辑、新成本账本、恢复已被清理的原始用量、自动更改一号机历史数据、未经同意提交或部署。

## 2026-10-26 执行前提收敛：停流量重算

用户明确：重算会在停止所有请求的情况下进行，不会有新增记录，要求避免复杂化。

正式操作流程仅为：停止请求入口并等待在途请求结束 → 数据库备份 → 现存明细预览/确认重算 → 核对财务、账号、看板 → 恢复请求。停流量由操作人员完成；本页面不会自行停服务或创建备份。

不支持/不再扩展在线并发重算算法、自动停流量编排、全库历史补证或撤销。保留已实现的整日对账、旧值审计和单事务原子执行；锁只是误操作防护。恢复请求后的正常汇总不能被旧日期标记冻结，因此保留已验证的小范围标记版本修复（前向迁移260；不改257/258或其他任务的259）。

此授权仍不包含提交、推送、部署或修改一号机账目。
