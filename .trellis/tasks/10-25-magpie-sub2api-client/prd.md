### R-AUTH 直接登录

- 复用本站邮箱/密码登录接口，客户端内完成输入和提交，不跳转浏览器，不新增 OAuth/设备授权机制。
- 用户确认目标站点不启用验证码及 2FA；本期不做验证码或 2FA 输入、SDK 和专用页面。此为部署前提，不是要求删除服务端既有安全能力。
- 处理登录错误、网络失败、会话刷新和退出；密码不持久化，令牌不进入日志/URL/诊断。
- 若接口意外要求额外验证或没有返回有效登录令牌，显示不支持当前验证配置的错误并停止；不得把挑战响应当登录成功，不绕过服务端检查。

### R-UI 新增 UI 风格约束

- 登录及必要状态 UI 必须像原版自带功能，不移植 sub2api 的 Vue 页面风格，不引入新的视觉系统或另做首页/导航。
- 复用原版颜色变量、字体、字号层级、间距、圆角、图标规范、按钮、输入框、弹窗及错误/加载状态模式。
- 兼容原有浅色、深色、系统主题、文字缩放与窄窗口；保留原版交互及本地化机制。
- 视觉依据：上游 `internal/gui/assets/app.css:1`、`theme.js:1`、`index.html:24`。浅色背景/卡片为 #f4f4f6/#ffffff，深色为 #1a1a1e/#232327；这些只记录基线，新增样式应引用变量，不复制硬编码。

### R-BOUNDARY 裁剪边界

- 删除“供应商/账号导入”不得误删旧会话迁移，不是跨设备迁移或跨 Agent 转换。
- 删除外部插件产品模块，不可直接删除保留功能依赖的内部插件注册/运行机制。发现依赖冲突先调查并报告，不擅自扩大删除清单。
- 账号 JWT 与模型 API Key 分开使用；不得绕过验证码/2FA，不把密码或凭据放入日志、URL、诊断文件。
- 删除功能必须覆盖 UI、CLI/API 调用入口、启动任务和外部请求，不能仅 CSS 隐藏。
- 保留功能不构成新增同类功能授权；远程数据失败不偷偷改用本地估算费用。

## 明确不做

- 从零重写客户端、换前端框架、重新设计 UI 或扩大功能范围。
- 跨设备会话同步、Codex 到其他 Agent 的会话转换。
- 本地会话精确计费、会话与远端 usage_logs 关联。
- 用户未要求的专用管理中心、充值实现、设备管理系统、权限套餐或新路由系统。
